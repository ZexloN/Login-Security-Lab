# 🔐 Login Security Lab

A small browser-based login security laboratory built with pure HTML, CSS and JavaScript.

This project simulates a login system and demonstrates some basic authentication security concepts in a safe, local environment.

## 🚀 Features

- 🔑 Login simulation
- 📊 Password strength meter
- 🔢 Failed login attempt counter
- 🛡️ Rate limiting simulation
- 👤 Session status
- 📋 Real-time security event log
- 💾 Runs entirely in the browser
- ⚡ No backend or database required

## 🎯 Purpose

The goal of this project is to demonstrate basic web authentication and security concepts through an interactive interface.

It is designed for educational purposes and does **not** interact with real accounts, servers or authentication systems.
